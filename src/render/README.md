# 3D drawing with three.js

- Builds the table from `src/data`: outline, rail, felt, legs, walls, tape graphics, betting trays.
- Bumpers with lights that turn green, blue or dark.
- Glowing teriks and frosted obstacle balls.
- Bar lighting: dim ambient, overhead lights, shadows, haze.
- Win light show and the hexagon glow when the hole opens.
- Camera presets: Overhead, Player and Bar.
